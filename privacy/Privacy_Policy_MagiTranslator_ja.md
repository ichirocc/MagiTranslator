## 1. このポリシーについて

このポリシーは、Android アプリ「MagiTranslator」（以下「本アプリ」）が扱う情報について説明するものです。
本アプリは、オープンソースの翻訳アプリ RTranslator（作者：Luca Martino）を元に、【運営者名】が改変・配布しています。
本アプリに関するお問い合わせ先は、RTranslator の作者ではなく、下記の運営者です。

## 3. 運営者が受け取る情報

**運営者は、本アプリの利用者の情報を受け取りません。**
本アプリには運営者のサーバーがなく、利用状況の分析、広告、クラッシュ報告のための仕組み（Firebase、Crashlytics など）も入っていません。

## 4. 端末の中で扱う情報

本アプリは、次の情報を利用者の端末の中だけで扱います。

| 情報 | 使い道 | 保存 |
|---|---|---|
| マイクの音声 | 音声認識（Whisper）。端末の中で文字にする | 音声は保存しない |
| 認識した文章・翻訳した文章 | 画面表示と読み上げ | アプリを使っている間だけメモリに保持 |
| ユーザー名・プロフィール画像（任意） | 会話モードで相手に表示する | 端末内に保存 |
| 会話した相手の名前・画像・端末の識別子 | 「最近の相手」の表示 | 端末内に保存 |
| 設定（言語、モードなど）、用語集（`jane_glossary.tsv`） | アプリの動作 | 端末内に保存 |

端末のバックアップ機能による保存の対象外にしています（`allowBackup=false`）。
保存された情報は、アプリのデータ削除またはアンインストールで消えます。

## 5. 外部に送られる情報

### 5.1 モデルのダウンロード（GitHub）

翻訳と音声認識のモデルは、初回起動時と「モデル管理」画面で、GitHub（`github.com`）上の本アプリのリリースからダウンロードします。
このとき GitHub には、通常のウェブ通信と同じく、利用者の IP アドレスなどが送られます。
GitHub での扱いは、GitHub のプライバシーに関する方針に従います。運営者はこの情報を受け取りません。

### 5.2 会話モード（Bluetooth）

会話モードでは、つないだ相手の端末に、Bluetooth で次の情報を送ります。

- 利用者が話して認識された文章（相手の端末が、相手の言語に翻訳します）
- ユーザー名とプロフィール画像

インターネットは使いません。相手の端末に届いた情報は、相手の端末で扱われます。

### 5.3 読み上げ

翻訳結果の読み上げには、端末に設定された読み上げエンジン（例：Google の音声サービス）を使います。
エンジンによっては、文章がそのエンジンの提供者に送られて処理される場合があります。その扱いは、各提供者の方針に従います。

## 6. 権限

| 権限 | 使い道 |
|---|---|
| マイク | 音声認識 |
| 近くのデバイス（Bluetooth） | 会話モードでの接続。位置情報の取得には使いません |
| 通知 | ダウンロード中や音声モード実行中の表示 |
| インターネット | モデルのダウンロード |

位置情報の権限は、Android 11 以前の Bluetooth 検索のための宣言だけです。本アプリが対応する Android 16 以降では、要求されません。
