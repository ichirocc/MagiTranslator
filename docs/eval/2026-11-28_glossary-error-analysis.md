## 日→ネ：50点に届かない原因と、主語のない定型文（2026-11-28 追記）

- 日→ネで50点未満は80文中50文。内訳（目視）：言い換え・同義語 約20、短い相づち 約8、文末の है/नि 抜け 約8、本当の誤訳 約14。
- 0.8B と 2B の良い方を毎回選べた場合の上限でも A 47.4 / B 55.7。参照訳1つの chrF では、訳の選び方では A は50に届かない。
- 本当の誤訳のうち、主語のない定型文は人称を取り違える：隣で見守っていますね→「あなたが見ている」、お待たせしました→「あなたが待たせた」、手が離せない→「手を動かせない」。
- 対策：`JaIdioms.rewrite` がモデルに渡す前に、主語を補った平易な日本語へ書き換える（手が離せない→私は他の仕事をしている、お待たせしました→待たせてごめんなさい、主語のない「見守っています」→私が見守っています）。会話履歴には元の文を残す。
- 辞書：手が離せない・かぼちゃ・深爪・左上/右上/左下/右下・変動を追加、おかげさまで→तपाईंहरूको शुभकामनाले。
- 結果（日→ネ chrF++）：A 44.6→44.9、B 50.2→50.3。対象の3文は正しい人称・意味になった（म अरू काम गरिरहेको छु / म हेरिरहेको छु）。
