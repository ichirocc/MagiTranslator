# 外部AIへの依頼文（そのまま貼る）

以下の各行は「ID<TAB>日本語<TAB>訳A<TAB>訳B」です。日本語を介護・生活の会話としてネパール語に訳した2案です。
各行について、意味が正確で、ネパール語として自然な方を選んでください。

- 訳抜け・意味の違い・人称（私/あなた）の取り違え・否定の逆転を最も重く見る。
- 次に、ネパール語として自然か（直訳調・不自然な語）。
- 差がほとんど無ければ same。
- 説明は書かず、1行に1件、`ID<TAB>A` / `ID<TAB>B` / `ID<TAB>same` の形だけで答える。

（ここに check.tsv の全行を貼る。合格したら kd.tsv を100行ずつ貼る）

# 手順

1. `check.tsv`（67行。「正解」は参照訳との chrF++ が高い方で、参照訳1つに基づく目安。完全な正解ではない）を貼り、答えを `answers_check.tsv` に保存。
2. `python3 read_answers.py check answers_check.tsv` で一致率を見る。**偶然（約50%）を明らかに超えなければ、そのAIの判定は使わない**。
3. 合格なら `kd.tsv`（724行）を判定させ、答えを `answers_kd.tsv` に保存（複数回に分けたら連結）。
4. `python3 read_answers.py kd answers_kd.tsv` で学習データ（SFT: 選ばれた訳、DPO: 選ばれた/選ばれなかった組）を作る。
