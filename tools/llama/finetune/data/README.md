# 学習・評価データ（2026-11-27 公開）

`dictionaries/` の会話集・用語から作ったデータ。所有者の判断で公開。`models/personal/` のアダプタはこれで学習した。

| ファイル | 中身 |
|---|---|
| `train.jsonl` | 学習用 8423 例（`build_data.py` の出力：PFML3 の指示文と訳、両方向、用語集・前の文つきを含む） |
| `dev.tsv` | 開発用 120 組（221 行、両方向）。チェックポイントの選択に使用 |
| `test80.tsv` | テスト 80 文（言語<TAB>原文）。`train.jsonl` との完全一致 0（学習外）。ただし会話集の文 |
| `blind_src.tsv` / `blind_ref.tsv` | ブラインド評価 100 文（原文と参照訳を別ファイル）。**注意（2026-11-28）**：100文とも会話集にあり、87文は `train.jsonl` の原文にも入っている。このアダプタの未知文の評価には使えない |
| `kd2_sources.tsv` | 蒸留（2回目）の原文：会話 1800 文（日 900・ネ 900）。dev・ブラインド・テストと似た文は除外 |
| `kd2_teacher_translations.tsv` | 同じ原文の先生（2B＋辞書アダプタ step 527）の訳 |
| `kd2_student_translations.tsv` | 同じ原文の生徒（0.8B＋辞書アダプタ step 600）の訳 |

入れていないもの：蒸留の原文のうち介護ニュース記事と介護福祉士国家試験の文 300 文（記事・試験問題の本文はリポジトリに置かない）、先生の上位32語の確率（大きく、上のファイルから作り直せる）。
| `claude_pairs.tsv` | Claude（このリポジトリの作業をした AI）が自分で書いた日本語–ネパール語の例文 161 組（分野<TAB>日本語<TAB>ネパール語）。受付・症状・診察・薬・入院・介護・仕事・役所・学校・日常・緊急。既存の教材の写しではない。ネイティブ未確認なので、使う前に見直すこと。dev・ブラインド・テストと同じ文は除外 |

入れていないもの（追加分）：JICA 駒ヶ根訓練所・佐久総合病院「医療支援用 指さし外国語フレーズ集（ネパール語）」から取り出した 503 組。冊子に「無断で転載、改変することを禁じます」とあるため、対訳はリポジトリに置かず、手元の学習（第3ラウンド）にだけ使う。取り出し方は `../jica_ocr.py`（罫線でセルを分け、ネパール語は tesseract nep、日本語は PDF の文字データ）。OCR の誤り（特に ु・ू の脱落）は全組を目で見て直した。
