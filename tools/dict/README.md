# 教科書などから辞書の語を取り入れる（textbook_terms.py）

介護の教科書、研修資料、施設のマニュアルなど、**手元にある資料**から語を取り出すツールです（Python 3 標準ライブラリだけ。PDF には `pdftotext`（poppler-utils）が必要）。

## 著作権について
- 個々の単語に著作権はありませんが、教科書の「日本語⇄ネパール語の用語集」は、まとまりとして著者の著作物です。
- このツールの出力は **自分の端末で使う私用の辞書** として扱ってください。アプリの設定 →「辞書ファイルを読み込む」で読み込めます。
- 出版物から作った組を、公開リポジトリの `dictionaries/` には入れないでください。資料の利用条件が許す場合（例：政府標準利用規約の資料を出典付きで使う）は別です。

## 使い方

### 1. 日本語の教科書から、よく出る介護・医療の語を調べる
```
python3 tools/dict/textbook_terms.py terms 教科書.pdf --top 200 > candidates.tsv
```
各語の出現数と、すでに辞書にあるか（dictionary）・確認待ちの一覧にあるか（review）・新しい語か（new）が出ます。
new の語のネパール語は、ネパール語の話者と決めてください。

### 2. 日本語とネパール語の用語集から、組を取り出す
```
python3 tools/dict/textbook_terms.py glossary 用語集.pdf --out private_ja_ne_terms.tsv
```
1 行に日本語とネパール語の両方がある行（例：`入浴介助 …… नुहाउन सहयोग`）から組を作ります。
アプリの形式（1 行目 `#!jane ja-ne-terms`）で書き出すので、そのまま読み込めます。
規則に合わない行は書き出さず、画面に理由を表示します。**使う前に全行を確認してください。**

## テスト
```
python3 -I tools/dict/test_textbook_terms.py
```
テストには、このために書いた例文だけを使っています（教科書の文は使っていません）。
