## 手元の教科書・資料から語を取り入れる
`tools/dict/textbook_terms.py` で、手元の教科書や研修資料から介護・医療の語を取り出せます（使い方は `tools/dict/README.md`）。
出版物から作った組は **私用の辞書** として端末で読み込み、このフォルダには入れないでください（著作権のため）。

## 語の出どころ

`sources/` には、2026-11 の収集ごとに、使った（使わなかった）サイトや資料とその理由（利用規約、robots.txt）を、
URL と件数だけで記録しています。記事・試験問題・テキストの本文は保存していません。
`review/care_candidates.tsv` は、推奨どおりに決めた介護・医療の語の一覧です。ネパール語の母語話者
（できれば日本で働く介護職の人）による確認が残っています。
