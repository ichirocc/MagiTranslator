# 日本語⇄ネパール語の辞書（APK の外）

| ファイル | 1 行目 | 内容 |
|---|---|---|
| `ja_ne_terms.tsv` | `#!jane ja-ne-terms` | 日→ネの単語（日本語<TAB>ネパール語）。訳文に必ず含める訳語 |
| `ne_ja_terms.tsv` | `#!jane ne-ja-terms` | ネ→日の単語（ネパール語<TAB>日本語）。後置詞付きの形にも一致 |
| `phrases.tsv` | `#!jane phrases` | 日常のフレーズ（日本語<TAB>ネパール語[<TAB>ja>ne]）。発話全体が一致したら表の訳を使う |

## 端末に届くまで
1. このフォルダを変えてデフォルトブランチに push すると、ワークフロー「Publish dictionaries」がファイルを検査し、リリース `jane-dictionaries` のファイルを置き換えます。
2. アプリは初回起動時に、そのリリースから 3 ファイルをダウンロードして `files/jane/` に保存します。設定 →「辞書を更新」でいつでも取り直せます。
3. 設定 →「辞書ファイルを読み込む」で、手元の TSV に差し替えることもできます。種類は 1 行目で判断します。

APK を作り直さなくても、辞書だけ直して配れます。

## 安全のための決まり
- 保存する前に `DictionaryFiles.check` で全行を検査します（列の数、文字の種類、重複、1 MB 以下）。1 行でも不正なら、そのファイルは丸ごと使いません。
- 保存は一時ファイルを経由するので、途中まで書けたファイルが使われることはありません。
- 辞書がない・壊れているときは、辞書なしで翻訳します。
- モデルと違い、辞書の SHA-256 は APK に固定していません（固定すると辞書の更新に APK の更新が必要になるため）。そのかわり、配布元はこのリポジトリのリリースだけで、通信は HTTPS、内容は上の検査を通ったものだけです。

## その他のフォルダ（アプリは読みません）
- `review/`：訳語が定まっていない候補（例：`care_candidates.tsv` の認知症・入浴介助・デイサービス）。ネパール語話者が訳語を決めたら、上の辞書に移します。
- `sources/`：語を集めたときの記録。記事本文は入っていません。
  - `care_crawl_2026-11.md`：ニュースのクロール（対象サイト、robots.txt の判断、URL、出現数）
  - `wikidata_medical_2026-11.md`：Wikidata（CC0）のラベルから取った組と、元の項目 ID

## 手元の教科書・資料から語を取り入れる
`tools/dict/textbook_terms.py` で、手元の教科書や研修資料から介護・医療の語を取り出せます（使い方は `tools/dict/README.md`）。
出版物から作った組は **私用の辞書** として端末で読み込み、このフォルダには入れないでください（著作権のため）。
