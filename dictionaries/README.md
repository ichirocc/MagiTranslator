# ユーザー作成辞書（jane 形式）

ユーザー（リポジトリ所有者）が個人的に作成した辞書。アプリの「辞書ファイルを読み込む」で端末に取り込む。

| ファイル | 形式（1行目） | 行数 |
|---|---|---:|
| `ja_ne_terms.tsv` | `#!jane ja-ne-terms`（日本語<TAB>ネパール語） | 2,115（2026-11-27 に介護用語 47 語、試験分野〔介護福祉士・ケアマネ・看護師〕の用語 79 語を追加。Claude の下訳 89 語は未確認） |
| `ne_ja_terms.tsv` | `#!jane ne-ja-terms`（ネパール語<TAB>日本語） | 1,349 |
| `phrases.tsv` | `#!jane phrases`（日本語<TAB>ネパール語[<TAB>ja>ne]） | 3,788（うち ja>ne 専用 387） |

- 出典・権利は各ファイル冒頭のコメントを参照。公開は所有者の判断による（2026-11-25）。
- 一部のネパール語は MagiTranslator による機械生成で未レビュー（ファイル冒頭の注記）。検証状態は UNVERIFIED として扱う（SPEC_v2 第4部）。

## 手元の教科書・資料から語を取り入れる
`tools/dict/textbook_terms.py` で、手元の教科書や研修資料から介護・医療の語を取り出せます（使い方は `tools/dict/README.md`）。
出版物から作った組は **私用の辞書** として端末で読み込み、このフォルダには入れないでください（著作権のため）。
